# Budget & Investissements

Application Windows de suivi du budget mensuel, des investissements, du patrimoine, des voyages et des achats.

Ce dépôt sert uniquement à **distribuer les mises à jour** de l'application : chaque version est publiée dans l'onglet **Releases**, et l'application installée la télécharge et l'installe toute seule (Paramètres › Mises à jour).

- Aucune donnée personnelle n'est stockée ici : les données restent sur le PC de l'utilisateur.
- Chaque installateur est accompagné de son empreinte SHA-256, vérifiée par l'application avant l'installation.
